# voice-assisted-real-time-object-detection-system
This project is a Python-based Voice-Assisted Real-Time Object Detection System designed to aid visually impaired individuals by combining object detection with audio feedback. It uses YOLOv8 and OpenCV to detect objects like vehicles, people, traffic signs, and animals in real-time from video input. The system integrates pyttsx3 for text-to-speech output and speech recognition to support voice commands such as “start” and “stop,” enabling a fully hands-free experience. It estimates object direction and proximity to alert users effectively, making navigation safer. The system was tested with both day and night video footage to ensure reliability under different lighting conditions. Overall, this project demonstrates how AI, computer vision, and voice interaction can be combined to create impactful assistive technologies.
